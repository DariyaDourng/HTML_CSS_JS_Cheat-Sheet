CSS Grid

Two-dimensional layout with CSS Grid — containers, items, areas, and responsive tricks.

Grid Container

.grid {
  display: grid;   /* or inline-grid */

  /* Define columns */
  grid-template-columns: 200px 200px 200px;
  grid-template-columns: 1fr 2fr 1fr;         /* fractional units */
  grid-template-columns: repeat(3, 1fr);        /* 3 equal columns */
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); /* responsive */
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  grid-template-columns: 200px auto 100px;    /* fixed-auto-fixed */

  /* Define rows */
  grid-template-rows: 100px auto 100px;
  grid-template-rows: repeat(4, minmax(100px, auto));

  /* Gap */
  gap: 20px;
  row-gap: 20px;
  column-gap: 16px;

  /* Named template areas */
  grid-template-areas:
    "header  header  header"
    "sidebar content content"
    "footer  footer  footer";

  /* Auto-placed row/column sizes */
  grid-auto-rows: 100px;
  grid-auto-columns: 200px;
  grid-auto-flow: row | column | row dense | column dense;

  /* Alignment */
  justify-items: start | end | center | stretch;
  align-items: start | end | center | stretch;
  place-items: center;                        /* shorthand */
  justify-content: start | end | center | space-between | space-around | space-evenly;
  align-content: start | end | center | space-between;
  place-content: center space-between;
}

Grid Item Properties

.item {
  /* Place by line numbers (start / end) */
  grid-column-start: 1;
  grid-column-end: 3;        /* span 2 columns */
  grid-column: 1 / 3;        /* shorthand */
  grid-column: 1 / span 2;   /* span 2 from col 1 */
  grid-column: span 2;       /* span 2 from auto position */

  grid-row: 1 / 3;
  grid-row: 2 / span 3;

  /* Shorthand: row-start / col-start / row-end / col-end */
  grid-area: 1 / 1 / 3 / 3;

  /* Named area (from grid-template-areas) */
  grid-area: header;
  grid-area: sidebar;
  grid-area: content;
  grid-area: footer;

  /* Self-alignment */
  justify-self: start | end | center | stretch;
  align-self: start | end | center | stretch;
  place-self: center;
  z-index: 1;    /* grid items can overlap, control stacking */
}

Common Grid Layouts

/* Holy Grail Layout */
body {
  display: grid;
  grid-template:
    "header"   80px
    "main"     auto
    "footer"   60px
    / 1fr;
  min-height: 100vh;
}

/* Responsive card grid */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 24px;
}

/* Center item */
.wrapper {
  display: grid;
  place-items: center;
  height: 100vh;
}
