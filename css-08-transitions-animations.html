Transitions & Animations

CSS transitions, @keyframes, animation properties, and timing functions.

Transitions

.btn {
  background: blue;

  /* property | duration | timing-function | delay */
  transition: background 0.3s ease;
  transition: all 0.3s ease-in-out;
  transition: background 0.3s ease, transform 0.2s ease 0.1s;

  /* Individual properties */
  transition-property: background, transform;
  transition-duration: 0.3s;
  transition-timing-function: ease;
  transition-delay: 0.1s;
}

.btn:hover {
  background: darkblue;
  transform: scale(1.05);
}

Timing Functions

.el {
  transition-timing-function: ease;          /* slow-fast-slow (default) */
  transition-timing-function: linear;        /* constant speed */
  transition-timing-function: ease-in;       /* slow start */
  transition-timing-function: ease-out;      /* slow end */
  transition-timing-function: ease-in-out;   /* slow start and end */
  transition-timing-function: step-start;    /* instant jump */
  transition-timing-function: step-end;
  transition-timing-function: steps(4, end); /* 4 discrete steps */

  /* Custom cubic-bezier — use cubic-bezier.com */
  transition-timing-function: cubic-bezier(0.34, 1.56, 0.64, 1);  /* bounce */
}

@keyframes

/* Define the animation */
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.05); }
  100% { transform: scale(1); }
}

@keyframes spin {
  to { transform: rotate(360deg); }
}

@keyframes slideIn {
  from { transform: translateX(-100%); }
  to   { transform: translateX(0); }
}

Animation Properties

.el {
  /* name | duration | timing | delay | count | direction | fill-mode | play-state */
  animation: fadeIn 0.5s ease-out;
  animation: pulse 2s ease-in-out infinite;
  animation: spin 1s linear infinite;
  animation: slideIn 0.4s ease-out 0.2s both;

  /* Individual properties */
  animation-name: fadeIn;
  animation-duration: 0.5s;
  animation-timing-function: ease-out;
  animation-delay: 0.2s;
  animation-iteration-count: 1 | infinite | 3;
  animation-direction: normal | reverse | alternate | alternate-reverse;
  animation-fill-mode: none | forwards | backwards | both;
    /* forwards: hold last keyframe after ending */
    /* backwards: apply first keyframe during delay */
    /* both: forwards + backwards */
  animation-play-state: running | paused;

  /* Multiple animations */
  animation: fadeIn 0.5s ease, pulse 2s infinite 0.5s;
}

Performance Tips

/* Only animate these properties for best performance: */
/* transform (translate, scale, rotate), opacity */
/* They are handled by the GPU compositor */

/* Hint browser to optimize: */
.animated { will-change: transform, opacity; }

/* Respect user preferences */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

Staggered Animations

.list-item:nth-child(1) { animation-delay: 0ms; }
.list-item:nth-child(2) { animation-delay: 100ms; }
.list-item:nth-child(3) { animation-delay: 200ms; }
.list-item:nth-child(4) { animation-delay: 300ms; }
