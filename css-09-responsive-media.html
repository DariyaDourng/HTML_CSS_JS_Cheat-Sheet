Responsive & Media Queries

@media rules, breakpoints, fluid sizing with clamp(), and container queries.

@media Syntax

/* Applies when screen is 768px or wider */
@media (min-width: 768px) { }

/* Applies when screen is narrower than 768px */
@media (max-width: 767px) { }

/* Range syntax (modern) */
@media (768px <= width < 1200px) { }

/* Multiple conditions (AND) */
@media (min-width: 600px) and (max-width: 1199px) { }

/* OR */
@media (max-width: 600px), (orientation: landscape) { }

/* NOT */
@media not screen { }

/* Media types */
@media screen { }   /* screens */
@media print  { }   /* printing */
@media all    { }   /* all devices */

Common Breakpoints

/* Mobile first approach */
/* Default: mobile styles */

@media (min-width: 480px)  { /* Small phones landscape */ }
@media (min-width: 640px)  { /* Small tablets */ }
@media (min-width: 768px)  { /* Tablets */ }
@media (min-width: 1024px) { /* Laptops */ }
@media (min-width: 1280px) { /* Desktops */ }
@media (min-width: 1536px) { /* Large screens */ }

Other Media Features

@media (orientation: portrait)  { }
@media (orientation: landscape) { }

/* User prefers dark mode */
@media (prefers-color-scheme: dark)  {
  body { background: #0a0a0f; color: #f0f0f0; }
}
@media (prefers-color-scheme: light) { }

@media (prefers-reduced-motion: reduce) { }
@media (prefers-contrast: high)  { }
@media (hover: hover)   { }  /* pointer device with hover */
@media (hover: none)    { }  /* touch device */
@media (pointer: coarse){ }  /* finger/touch */
@media (pointer: fine)  { }  /* mouse/stylus */
@media (display-mode: standalone) { }  /* PWA installed */
@media print { .no-print { display: none; } }

Fluid Sizing — clamp(), min(), max()

.el {
  /* clamp(minimum, preferred, maximum) */
  font-size: clamp(1rem, 2.5vw, 2rem);
  width: clamp(300px, 50%, 800px);
  padding: clamp(1rem, 3vw, 2rem);

  /* min(): use smaller of two values */
  width: min(80%, 600px);

  /* max(): use larger of two values */
  padding: max(1rem, 3vw);
}

/* Viewport units */
.hero {
  height: 100vh;    /* full viewport height */
  height: 100svh;   /* small viewport height (excludes browser chrome) */
  height: 100dvh;   /* dynamic viewport height */
  width: 100vw;
  font-size: 5vw;   /* 5% of viewport width */
  font-size: 2vmin; /* 2% of smaller dimension */
}

Container Queries

/* 1. Define a containment context */
.card-container {
  container-type: inline-size;  /* enable width queries */
  container-name: card;          /* optional name */
}

/* 2. Query the container size */
@container (min-width: 400px) {
  .card { display: flex; }
}

@container card (min-width: 600px) {
  .card__image { width: 50%; }
}
