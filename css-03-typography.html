Typography

All CSS font and text properties — from font-family to text transforms.

Font Properties

.text {
  font-family: 'Georgia', serif;
  font-family: 'Roboto', 'Helvetica Neue', sans-serif;
  font-size: 16px;        /* px, rem, em, %, vw */
  font-size: 1rem;        /* relative to root (html) */
  font-size: 1.2em;       /* relative to parent */
  font-weight: normal;    /* 400 */
  font-weight: bold;      /* 700 */
  font-weight: 300;        /* light */
  font-weight: 900;        /* black */
  font-style: normal | italic | oblique;
  font-variant: normal | small-caps;
  font-stretch: condensed | normal | expanded;

  /* Shorthand: style variant weight size/line-height family */
  font: italic bold 1.2rem/1.5 'Georgia', serif;
}

Text Properties

.text {
  color: #333;
  line-height: 1.6;            /* unitless = best practice */
  letter-spacing: 0.05em;      /* tracking */
  word-spacing: 0.1em;

  text-align: left | center | right | justify | start | end;
  text-transform: none | uppercase | lowercase | capitalize;
  text-decoration: none | underline | overline | line-through;
  text-decoration: underline dotted red 2px;
  text-decoration-line: underline;
  text-decoration-style: solid | double | dotted | dashed | wavy;
  text-decoration-color: blue;
  text-decoration-thickness: 2px;
  text-underline-offset: 4px;

  text-indent: 2em;
  text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
  text-shadow: 0 0 20px cyan, 0 0 40px blue;  /* multiple shadows */

  white-space: normal | nowrap | pre | pre-wrap | pre-line | break-spaces;
  word-break: normal | break-all | keep-all | break-word;
  overflow-wrap: normal | break-word | anywhere;
  hyphens: auto | manual | none;

  text-overflow: clip | ellipsis;  /* needs overflow:hidden & white-space:nowrap */

  writing-mode: horizontal-tb | vertical-rl | vertical-lr;
}

@font-face — Custom Fonts

@font-face {
  font-family: 'MyFont';
  src: url('font.woff2') format('woff2'),
       url('font.woff')  format('woff');
  font-weight: 400;
  font-style: normal;
  font-display: swap;  /* show fallback while loading */
}

/* Google Fonts via @import */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap');

Multi-column Text

.article {
  column-count: 3;
  column-gap: 2rem;
  column-rule: 1px solid #ccc;
  column-width: 250px;    /* auto-calculate columns */
  columns: 3 250px;       /* shorthand */
}
.no-break { break-inside: avoid; }  /* don't split this element across columns */
