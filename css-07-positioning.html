Positioning

All CSS position values, z-index, stacking contexts, and transforms.

Position Values

/* static (default) — follows document flow, top/left etc. have no effect */
.el { position: static; }

/* relative — offset from its own normal position; still in flow */
.el {
  position: relative;
  top: 10px;    /* down 10px from where it would normally be */
  left: 20px;
  /* Also creates a new stacking context for children */
}

/* absolute — removed from flow; positioned relative to nearest
   positioned (non-static) ancestor */
.parent { position: relative; }
.child {
  position: absolute;
  top: 0;
  right: 0;
  bottom: 0;
  left: 0;  /* fill parent */
}

/* fixed — relative to viewport; stays when scrolling */
.navbar {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  z-index: 100;
}

/* sticky — scrolls with page until threshold, then sticks */
.section-header {
  position: sticky;
  top: 60px;   /* sticks when within 60px of top */
  z-index: 10;
}

Inset Shorthand

.el {
  inset: 0;                      /* top right bottom left = 0 */
  inset: 10px 20px;              /* top/bottom | left/right */
  inset: 10px 20px 30px 40px;   /* top right bottom left */
  inset-block: 0;                /* logical: top + bottom */
  inset-inline: 0;               /* logical: left + right */
}

Z-index & Stacking Context

.low   { z-index: 1; }
.mid   { z-index: 10; }
.high  { z-index: 100; }
.modal { z-index: 1000; }
.toast { z-index: 9999; }

/* Stacking context is created by:
   - position + z-index (not auto)
   - opacity < 1
   - transform, filter, will-change
   - isolation: isolate
*/
.isolated { isolation: isolate; }  /* create new stacking context */

Transform

.el {
  /* Translate (move) */
  transform: translateX(50px);
  transform: translateY(-20px);
  transform: translate(50px, -20px);
  transform: translate(50%, -50%);  /* % of element's own size */
  translate: 50px -20px;             /* standalone property (modern) */

  /* Scale */
  transform: scale(1.5);
  transform: scaleX(2) scaleY(0.5);
  scale: 1.5;  /* standalone */

  /* Rotate */
  transform: rotate(45deg);
  transform: rotate(0.5turn);
  rotate: 45deg;  /* standalone */

  /* Skew */
  transform: skew(15deg, 10deg);

  /* 3D transforms */
  transform: rotateX(45deg) rotateY(30deg);
  perspective: 500px;
  transform-style: preserve-3d;
  backface-visibility: hidden;

  /* Chaining transforms */
  transform: translateY(-4px) scale(1.02);

  /* Origin of transform */
  transform-origin: center center;  /* default */
  transform-origin: top left;
  transform-origin: 0% 0%;
}

Centering with Position + Transform

/* Classic absolute centering */
.centered {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
