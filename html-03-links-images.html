Links & Images

Anchor tags, image embedding, responsive images, and figure elements.

Anchor Tag — All Variations

<!-- External link -->
<a href="https://example.com">Visit Example</a>

<!-- Open in new tab (+ rel for security) -->
<a href="https://example.com"
   target="_blank"
   rel="noopener noreferrer">Open in new tab</a>

<!-- Internal page link -->
<a href="about.html">About page</a>

<!-- Anchor to section on same page -->
<a href="#section-id">Jump to section</a>
<h2 id="section-id">Target Section</h2>

<!-- Email link -->
<a href="mailto:user@example.com?subject=Hello&body=Hi there">Send Email</a>

<!-- Phone link -->
<a href="tel:+15550001234">Call us</a>

<!-- Download link -->
<a href="file.pdf" download="my-file.pdf">Download PDF</a>

<!-- Image as link -->
<a href="https://example.com">
  <img src="logo.png" alt="Go to Example"/>
</a>

Image Element

<!-- Basic image (src and alt are required) -->
<img src="photo.jpg" alt="A scenic mountain view"/>

<!-- With explicit width/height (prevents layout shift) -->
<img src="photo.jpg" alt="Photo" width="800" height="600"/>

<!-- Lazy loading (only loads when near viewport) -->
<img src="photo.jpg" alt="Photo" loading="lazy"/>

<!-- Decorative image (empty alt = ignored by screen readers) -->
<img src="divider.svg" alt="" role="presentation"/>

Responsive Images — srcset & sizes

<!-- srcset: list image variants by width -->
<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w,
          photo-800.jpg 800w,
          photo-1600.jpg 1600w"
  sizes="(max-width: 600px) 100vw,
         (max-width: 1200px) 50vw,
         800px"
  alt="Responsive photo"/>

Picture Element (Art Direction)

<!-- picture: different image for different screens -->
<picture>
  <!-- Modern format first (WebP) -->
  <source srcset="photo.webp" type="image/webp"/>

  <!-- Mobile crop -->
  <source media="(max-width: 600px)" srcset="photo-portrait.jpg"/>

  <!-- Fallback -->
  <img src="photo.jpg" alt="Photo"/>
</picture>

Figure & Figcaption

<figure>
  <img src="chart.png" alt="Sales chart for Q4 2024"/>
  <figcaption>Figure 1: Q4 2024 sales by region</figcaption>
</figure>
Accessibility: Always write meaningful alt text describing the image's content and purpose. Avoid "image of..." or "photo of..." — just describe what's there.
