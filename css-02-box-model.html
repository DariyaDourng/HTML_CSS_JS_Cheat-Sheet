Box Model

How every element is sized: content, padding, border, margin, and display modes.

The Box Model

/* content-box (default): width = content only */
.box {
  width: 200px;
  padding: 20px;      /* adds 40px to total */
  border: 2px solid;   /* adds 4px to total */
  /* total rendered width = 266px */
}

/* border-box: width INCLUDES padding + border */
* { box-sizing: border-box; }  /* recommended globally */
.box {
  width: 200px;
  padding: 20px;
  border: 2px solid;
  /* total rendered width = 200px exactly */
}

Margin

.box {
  margin: 20px;                      /* all sides */
  margin: 10px 20px;                /* top/bottom | left/right */
  margin: 10px 20px 30px;          /* top | left/right | bottom */
  margin: 10px 20px 30px 40px;    /* top right bottom left (clockwise) */
  margin-top: 10px;
  margin-right: 20px;
  margin-bottom: 10px;
  margin-left: 20px;
  margin: 0 auto;                    /* center block horizontally */
  margin-inline: auto;              /* logical: horizontal centering */
}

Padding

.box {
  padding: 16px;
  padding: 8px 16px;
  padding-block: 12px;    /* logical: top + bottom */
  padding-inline: 16px;   /* logical: left + right */
}

Border

.box {
  border: 2px solid #333;
  border-width: 2px;
  border-style: solid | dashed | dotted | double | groove | ridge | inset | outset | none;
  border-color: red;
  border-radius: 8px;           /* rounded corners */
  border-radius: 50%;            /* circle (on square element) */
  border-radius: 10px 20px 30px 40px; /* each corner */
  border-top: 4px solid blue;
}

Width & Height

.box {
  width: 300px;
  height: 200px;
  min-width: 100px;
  max-width: 600px;
  min-height: 50px;
  max-height: 400px;
  width: 100%;          /* % of parent */
  width: 50vw;          /* 50% of viewport width */
  height: 100vh;        /* full viewport height */
  width: fit-content;   /* shrink to content */
  width: min-content;
  width: max-content;
}

Display

.el {
  display: block;         /* full width, new line */
  display: inline;        /* flows with text, no width/height */
  display: inline-block;  /* inline but accepts width/height */
  display: flex;          /* flexbox container */
  display: inline-flex;
  display: grid;          /* grid container */
  display: inline-grid;
  display: none;          /* hidden, removes from layout */
  display: contents;      /* element itself disappears, children remain */
  display: table;         /* table behaviour */
  display: list-item;     /* behaves like li */
}

/* visibility: hidden hides but keeps space */
.el { visibility: hidden; }

/* overflow */
.el {
  overflow: visible | hidden | scroll | auto | clip;
  overflow-x: hidden;
  overflow-y: auto;
}

Outline

.el:focus {
  outline: 2px solid #00ffd1;
  outline-offset: 4px;   /* space between outline and element */
  /* outline does NOT affect layout (unlike border) */
}
