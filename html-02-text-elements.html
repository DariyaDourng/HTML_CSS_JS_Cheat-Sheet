Paragraphs & Line Breaks

<p>This is a paragraph. Browsers add space above and below automatically.</p>

<p>
  Long text can be broken<br>
  with a line break tag. br is a void element (no closing tag).
</p>

<hr>

Inline Text Formatting

<strong>Bold — semantically important</strong>
<b>Bold — stylistic only (no importance)</b>

<em>Italic — stress emphasis (semantic)</em>
<i>Italic — stylistic or technical terms</i>

<u>Underlined text</u>
<s>Strikethrough — no longer accurate</s>
<del>Deleted text (shows red in some browsers)</del>
<ins>Inserted text</ins>

<mark>Highlighted / marked text</mark>
<small>Smaller font — fine print</small>

<sup>Superscript</sup>  <!-- e.g. x² -->
<sub>Subscript</sub>    <!-- e.g. H₂O -->

<code>Inline code snippet</code>
<kbd>Ctrl</kbd> + <kbd>C</kbd>  <!-- keyboard input -->
<samp>Program output</samp>
<var>x</var> = <var>y</var> + 2  <!-- variable -->

Abbreviations & Quotes

<!-- abbr: shows full form on hover -->
<abbr title="HyperText Markup Language">HTML</abbr>

<!-- blockquote: long quote from external source -->
<blockquote cite="https://example.com">
  <p>This is a long quotation from somewhere.</p>
</blockquote>

<!-- q: inline short quote -->
<p>He said <q cite="https://example.com">hello</q> and left.</p>

<!-- cite: title of creative work -->
<cite>The Great Gatsby</cite>

Preformatted & Code Blocks

<!-- pre: preserves whitespace and line breaks -->
<pre>
  This  text
    preserves    spacing
      and newlines.
</pre>

<!-- pre + code: best practice for code blocks -->
<pre><code>
function hello() {
  console.log("world");
}
</code></pre>

Generic Containers

<!-- div: block-level generic container -->
<div class="container">
  <p>Block-level content here</p>
</div>

<!-- span: inline generic container -->
<p>Text with <span class="highlight">styled word</span> inside.</p>
Semantic tip: Use <strong> and <em> for meaning, not just visual styling. Screen readers announce them differently from <b> and <i>.
